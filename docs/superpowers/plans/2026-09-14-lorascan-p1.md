# lorascan P1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A pip-installable `lorascan` that, with an SX1262 on a Debian SPI bus, sweeps 902–928 MHz (energy layer), stores every measurement in SQLite, and renders a heat map + band summary as a self-contained HTML report; validated on the bench Nebra HAT against infrad's `bandscan`.

**Architecture:** thin HAL (fake / spidev+gpiod) → SX1262 command layer (the sequences proven in `infra/crates/sx126x`) → energy sampler (polled `GetRssiInst`; Semtech scan-patch histogram behind a feature flag once verified on the HAT) → plan generator (quick / survey) → SQLite writer → report renderer (plotly.js from cdnjs, no Python plotting deps) → argparse CLI.

**Tech Stack:** Python 3.11 (Debian 12), stdlib `sqlite3`/`argparse`/`json`, optional extras `spidev`, `gpiod` (v1 API 1.6 on Debian 12; v2 tolerated), `numpy` optional (not required), `pytest` for tests. No pyserial, no matplotlib.

## Global Constraints
- Receive-only in P1: the driver exposes no `transmit`; `SetTxParams` is never called with power above −9 dBm (the infrad bench value) and no TX opcode exists in P1 code.
- Every measurement row stores the raw data (`hist` counts or sample list) plus derived fields; derived thresholds are parameters with stated defaults: busy threshold `T = 8 dB` above floor (spec §3.2), floor = P10, `busy_frac` = fraction of samples > floor + T.
- RSSI is relative unless a board profile sets `rssi_offset_db`; reports print "relative (uncalibrated)" when it is 0/absent.
- Board profile YAML keys exactly as spec §3.1: `name, bus{type,dev,hz}, pins{nss,reset,busy,dio1,rxen,txen}, radio{tcxo_v,dio2_rf_switch,rx_boosted,max_tx_dbm}, cal{rssi_offset_db,scan_offset_dbm}`. Profiles are JSON-compatible YAML; P1 parses them with a 40-line subset parser (no PyYAML dependency) — keys, nested maps, numbers, `null`/`true`/`false`, strings.
- Init sequence = infrad's (reset → STDBY_RC → DIO3 TCXO 1.8 V 5 ms → clear errors → Calibrate 0x7F → tolerate only RC64K error bit → PacketType LoRa → CalibrateImage 0xE1 0xE9 → SetRfFrequency → SetPaConfig 04 07 00 01 → SetTxParams(−9, 0x04) → DIO2 RF switch → buffer base → ModParams(sf, bw, cr−4, ldro) → sync word regs 0x0740/41 → RX gain 0x08AC = 0x96 → DIO IRQ params). Frequency step = 32e6 / 2^25.
- Unsettled `GetRssiInst` reads (≥ −1 dBm or ≤ −126 dBm) are discarded, and the first 20 ms after `SetRx` are discarded.
- Bench validation acceptance: on the 14 KD4HME channels, floors within ±3 dB of a same-day `infrad bandscan 6` run and the same busy ranking of the top 3 (spec §3.7).

## File structure
```
lorascan/                      package
  __init__.py                  version
  profile.py                   BoardProfile dataclass + load_profile(path|name) + mini YAML parser
  hal/__init__.py              Hal protocol (xfer, busy, dio1, reset_low/high, sleep) + open_hal(profile)
  hal/fake.py                  FakeHal: scripted replies keyed by opcode; records every transfer
  hal/spidev_gpiod.py          SpidevGpiodHal: spidev + gpiod v1/v2 (+ lgpio fallback)
  radio/sx126x.py              Sx126x: cmd/read_reg/write_reg, reset, init, set_frequency, rx_continuous, standby, rssi_inst, device_errors, chip_status, probe_bytes
  radio/scanpatch.py           (task 10) patch upload + spectral_scan(nb, interval) → hist[33]
  measure/energy.py            EnergyRow dataclass + polled_energy(radio, freq, bw, dwell_s) + stats(samples) + hist33(samples, offset)
  plan/grid.py                 band_grid(start, stop, step) + KNOWN_CHANNELS (the 14 KD4HME channels with labels)
  plan/quick.py                quick_plan(grid, passes, dwell) → iterator of Step
  plan/survey.py               survey_plan(grid, dwell, revisit_max) → infinite iterator with adaptive weighting
  store/db.py                  Store: open, new_run, add_energy, iter_energy, rollups
  report/html.py               render_report(db, out_html, run_id|None): heat map + band summary + when-matrix
  cli.py                       lorascan probe|selftest|scan quick|scan survey|report|export
profiles/                      nebra-duo-hat.yaml, generic-spidev.yaml
tests/                         one file per module
pyproject.toml, README.md, LICENSE (Apache-2.0)
```

### Task 10: Semtech scan-patch histogram engine (behind `--engine scan`)

**Produces:** `upload_patch(radio)` (the RadioLib upload sequence: `uploadPatch` writes the 6 KB word table at 0x8000 via WriteRegister in ≤ 64-byte chunks, then the patch-apply command 0xD9 with `[0x00, 0x00]`? — take the exact sequence from `SX126x::uploadPatch` in the RadioLib source in `client/.pio/libdeps/heltec_v3_wifi/RadioLib/src/modules/SX126x/SX126x.cpp`; transcribe it line by line into the task before implementing, do not guess), `spectral_scan(radio, nb_scan=2048, interval=0x0B, window=0x05<<2, timeout_s=2.0) -> list[int]` (write 0x089B = window, SetRx(0xFFFFFF), opcode 0x9B [nb>>8, nb, interval], poll 0x07CD until 0xFF, read 66 bytes at 0x0401 → 33 big-endian counts; 0xF0 → raise `ScanAborted`).
